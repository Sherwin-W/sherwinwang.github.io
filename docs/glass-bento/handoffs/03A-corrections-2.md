## Measured defects to fix (1440x900, 820x1100, 390x844, 195x420)

1. **Description-to-tag gap is 10px, must be 16px (`--space-body-tags`), never below 12.** A specificity clash (`.bento-slot--html .bento-tags, .bento-slot--flutter .bento-tags { margin:0 }` beats `.bento-tile__content > .bento-tags { margin: var(--space-body-tags) 0 0 }`) removes the margin so only the 10px title-body flex gap remains. Fix so that wherever a tag/chip row follows a description the distance is 16px, via a single mechanism (flex/grid `gap` or one margin rule, not competing ones).
2. **HTML Transformer and Flutter: restore the approved row layout and fix mobile height.** Desktop (>= 640px): inside `.bento-tile__content` use a grid: `grid-template-columns: minmax(0, 1fr) auto; column-gap: 24px; row-gap: var(--space-title-body)` with the title on row 1 col 1, description on row 2 col 1, and the tag list spanning both rows in col 2 (`align-self: center`). At 1440 the tile is about 140px tall with the tag at the right, vertically centered. Below 640px: a single column (title, description, then the tag with `--space-body-tags` above it); tile height must be natural (about 150-160px at 390), NOT 330px. Currently on mobile they are 330px tall with large empty space, caused by an unscoped `flex-direction: column` plus a flex-basis/min-height being applied to the column. Never apply a `flex-basis` or `min-height` greater than content to these in column layouts.
3. **Sketchbook lost its rounded corners and still clips at narrow widths.** Removing `overflow: hidden` left square corners. Use `overflow: clip` on the tile (or `border-radius` on the stage top corners and the text block bottom corners) so corners are rounded, with the 28px radius intact, without hiding any text (the tile grows with content). On tablet/mobile remove `aspect-ratio` from `.bento-slot--sketchbook .bento-tile` (there is a stale `aspect-ratio: 4 / 3` in the mobile block that fixes the height to 269px and clips: stage 170 + text 108 > 269). Tile height = stage (flex 1 1 auto, min 170px) + text block. At 195px width the tile must be tall enough for its text and no element may extend outside the tile (conductor measured edge distance -209px and a 122px tall tile there).
4. **Privacy desktop height is 310, approved 296.** Let the diagram flex smaller: `.bento-tile--privacy` artwork `flex: 1 1 96px; min-height: 96px`; keep padding 24, gaps 16/10/16 and all text intact. Target 296 +/- 4 at 1440; it may grow only if text wraps.
5. **Quest on tablet (640-1023px) is 697px tall; expected about 560-620.** Set the tablet media to `aspect-ratio: 2 / 1` (mobile stays 4 / 3; desktop stays flexible fill). Confirm the three panels remain inside the media at that ratio (reduce panel `clamp` max or offsets at tablet if needed, no overlap of panel text, caption bottom-left clear).
6. HTML/Flutter desktop height should be 140 (it is 147 now) once the row layout is restored.
